About This Website

DC Character Gallery

I created this website to show some of my favorite characters from the DC universe.

The website includes both heroes and villains like Batman, Superman, The Flash, The Joker, and Harley Quinn. Each character has a picture and some basic information about them.

I used HTML and Bootstrap to create the pages and organize the character cards. Bootstrap helped me create the navigation bar, columns, cards, and buttons.

This is a static website, so the search bar and the add character form do not actually save or search for characters.
